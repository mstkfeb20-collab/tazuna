# 要件（完了条件の正本）

要件と完了条件はこのフォルダに書く。管理者は社員（CODEOWNERS: business-team）。エージェントは編集できない（hooks で保護）。

## 書き方

- 1ファイル1機能領域（例: `billing.md`）。
- 要件ごとに `## REQ-001 タイトル` の見出しを付ける。番号は案件内で一意にし、使い回さない。
- 見出しの下に「背景」「完了条件」を書く。完了条件は、テストで確かめられる形（入力と期待結果）で書く。

## テストとの対応

- テストクラスに `@Tag("REQ-001")` を付けて要件と紐づける。
- `scripts/lint/common/requirement-traceability.sh` が、テストのない要件と、定義されていない要件IDを検出する。
- 要件を廃止するときは、見出しを削除し、対応するテストも削除する（テストの削除は人が行う）。
