# 業務用語集

お客様・社員・協力会社・エージェントが同じ言葉で話すための用語集。コード上の名前もここに合わせる。管理者は社員。

> 以下は見本です。案件では自分の用語に置き換えてください。

| 用語 | コード上の名前 | 意味 | 使わない言い方 |
| --- | --- | --- | --- |
| 請求書 | `Invoice` | 顧客に支払いを求める書類 | 伝票、ビル |
| 小計 | `subtotal` | 税抜の合計金額 | 本体価格 |
| 税込金額 | `totalWithTax` | 小計に消費税を加え、1円未満を切り捨てた金額 | 総額 |
| 下書き | `Status.DRAFT` | 作成直後で、まだ顧客に送っていない状態 | 仮登録 |
| 確定 | `Status.ISSUED` | 顧客に送付し、内容を変えられない状態 | 発行済、承認済 |
| 支払済 | `Status.PAID` | 入金を確認した状態 | 消込済 |
