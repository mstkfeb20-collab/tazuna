# 機能一覧

利用者から見た機能の一覧。要件・コード・テストを「同じ名前」で結びつけるための地図。管理者は社員。

> 以下は見本です。案件では自分の機能に置き換えてください。

| 機能 | 利用者 | 要件ID | 主なコード | 状態遷移 |
| --- | --- | --- | --- | --- |
| 請求書の作成 | 経理担当 | REQ-001 | `InvoiceService#createDraft` | → 下書き |
| 請求書の確定 | 経理担当 | REQ-002 | `InvoiceService#issue` | 下書き → 確定 |
| 入金の記録 | 経理担当 | REQ-002 | `InvoiceService#pay` | 確定 → 支払済 |

## 状態遷移（請求書）

```
下書き(DRAFT) ──issue()──▶ 確定(ISSUED) ──markPaid()──▶ 支払済(PAID)
```

新しい状態や遷移を追加するときは、実装より先にこの表と図を更新し、承認を得る。
