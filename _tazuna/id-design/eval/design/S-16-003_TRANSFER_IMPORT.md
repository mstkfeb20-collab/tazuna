# S-16-003 テーブル定義書：TRANSFER_IMPORT（振込取込結果）

> 振り分け評価のインプット。設計項目の見出しの下に、1行に1つの決定事項を書く。振り分け先は書かない。

## D-05001 テーブル定義

- S-16-003-001 TRANSFER_IMPORT.ACCOUNT_DATE DATE、TRANSFER_IMPORT.INQUIRY_NO CHAR(6)
- S-16-003-002 TRANSFER_IMPORT.AMOUNT NUMBER(10)
- S-16-003-003 TRANSFER_IMPORT.PAYER_NAME VARCHAR2(48)
- S-16-003-004 TRANSFER_IMPORT.RESERVE_NO VARCHAR2(13)
- S-16-003-005 TRANSFER_IMPORT.RESULT CHAR(2)
- S-16-003-006 TRANSFER_IMPORT.FILE_NAME VARCHAR2(64)
- S-16-003-007 TRANSFER_IMPORT は7年保持する

## D-05002 主キー・一意制約

- S-16-003-008 TRANSFER_IMPORT の主キーは ACCOUNT_DATE＋INQUIRY_NO

## D-05004 NULL可否・初期値

- S-16-003-009 TRANSFER_IMPORT.RESERVE_NO は、予約番号が読み取れなかった明細では NULL

## D-05011 データ量・増加見込み

- S-16-003-010 振込明細は平常1日300件、繁忙期は最大3千件
