# F-RV-11 振込データ取込（夜間バッチ） — 処理概要

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

- D-RV11-0101 F-RV-11 振込データ取込。銀行から届く振込入金通知ファイルを取り込み、予約を振込済にする
- D-RV11-0102 予約担当が毎朝手作業で行っている入金の消込をなくし、振込済への更新を朝7時までに済ませる
- D-RV11-0103 消し込めなかった入金は、予約担当が確認できるリストにまとめる
- D-RV11-0104 ジョブ J110 として、夜間ジョブネット /TOUR/NIGHTLY から起動する
- D-RV11-0105 入力は振込入金通知ファイル（取引銀行から1日1回）
- D-RV11-0106 出力は RESERVE の更新、取込結果テーブル、不一致リスト、返金対象リスト、通知メール
- D-RV11-0107 受信フォルダに振込入金通知ファイルが1つだけあること
- D-RV11-0108 取り込んだ明細は、すべて 消込済・不一致・返金対象・要確認 のどれかになっている
- D-RV11-0109 消し込めなかった明細は、すべて不一致リストか返金対象リストに出ている
- D-RV11-0110 受信確認 → 形式検査 → 明細の消込 → リスト出力 → ファイル退避 の順に行う
- D-RV11-0111 形式検査で1件でもエラーがあれば、消込を1件も行わない
- D-RV11-0112 振込明細は平常1日300件、繁忙期は最大3千件
- D-RV11-0113 振込取込の issue では、この機能の要件（docs/requirements/transfer.md）と、全銀協フォーマットの社内解説を読む
