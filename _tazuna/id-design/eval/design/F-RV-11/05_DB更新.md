# F-RV-11 振込データ取込（夜間バッチ） — DB更新

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 更新するテーブル

- D-RV11-0501 消込では RESERVE の TRANSFER・PAID_DATE・PAID_AMOUNT・LATE_PAYMENT_FLAG・VERSION を UPDATE する
- D-RV11-0502 明細は、消込済みも不一致も、すべて TRANSFER_IMPORT に INSERT する
- D-RV11-0503 J110 では RESERVE を INSERT・DELETE しない

## TRANSFER_IMPORT（取込結果）

- D-RV11-0504 TRANSFER_IMPORT.ACCOUNT_DATE DATE、TRANSFER_IMPORT.INQUIRY_NO CHAR(6)
- D-RV11-0505 TRANSFER_IMPORT.AMOUNT NUMBER(10)
- D-RV11-0506 TRANSFER_IMPORT.PAYER_NAME VARCHAR2(48)
- D-RV11-0507 TRANSFER_IMPORT.RESERVE_NO VARCHAR2(13)
- D-RV11-0508 TRANSFER_IMPORT.RESULT CHAR(2)
- D-RV11-0509 TRANSFER_IMPORT.FILE_NAME VARCHAR2(64)
- D-RV11-0510 TRANSFER_IMPORT の主キーは ACCOUNT_DATE＋INQUIRY_NO
- D-RV11-0511 TRANSFER_IMPORT.RESERVE_NO は、予約番号が読み取れなかった明細では NULL
- D-RV11-0512 TRANSFER_IMPORT.RESULT: '10' 消込済、'21' 予約なし、'22' 不足、'23' 超過、'31' 二重振込、'32' 取消後の入金、'40' 組戻し
- D-RV11-0513 TRANSFER_IMPORT は7年保持する

## RESERVE に追加する列

- D-RV11-0514 RESERVE.PAID_DATE DATE、RESERVE.PAID_AMOUNT NUMBER(9)、RESERVE.LATE_PAYMENT_FLAG CHAR(1)
- D-RV11-0515 PAID_DATE・PAID_AMOUNT は未振込の間 NULL
- D-RV11-0516 LATE_PAYMENT_FLAG は NOT NULL、初期値 '0'

## 更新のしかた

- D-RV11-0517 予約は RESERVE_NO の完全一致だけで探す
- D-RV11-0518 RESERVE の更新は版番号で行い、画面からの取消と競合したら、その明細は「要確認」にする
- D-RV11-0519 J110 が更新した行の UPDATED_BY は 'J110'
