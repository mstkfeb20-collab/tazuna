# F-RV-11 振込データ取込（夜間バッチ） — 処理詳細

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 照合

- D-RV11-0401 消込の相手になるのは TRANSFER = '0'（未振込）の予約
- D-RV11-0402 振込依頼人名の先頭13桁が R + 数字12桁 なら、予約番号とみなす
- D-RV11-0403 EDI情報に予約番号があれば、振込依頼人名より優先して使う
- D-RV11-0404 振込依頼人名に予約番号がなければ、氏名と金額が一致する未振込の予約が1件だけあっても自動では消し込まない

## 判定

- D-RV11-0405 予約番号の予約が見つからなければ「不一致（予約なし）」
- D-RV11-0406 振込額が合計金額と一致したら、予約を振込済にする
- D-RV11-0407 振込額が合計金額より少なければ「不一致（不足）」とし、振込済にしない
- D-RV11-0408 振込額が合計金額より多ければ「不一致（超過）」とし、振込済にしない
- D-RV11-0409 予約がすでに振込済なら「返金対象（二重振込）」
- D-RV11-0410 予約が取消済なら「返金対象（取消後の入金）」
- D-RV11-0411 取消区分が '1'（組戻し）の明細は消込に使わず、「要確認（組戻し）」として予約担当に回す
- D-RV11-0412 返金対象の金額は、その明細の振込額の全額
- D-RV11-0413 同じ予約への明細が同じファイルに2件あれば、照会番号の小さい方を消込に使い、もう1件は返金対象にする

## 期限

- D-RV11-0414 勘定日が振込期限を過ぎていても消し込む。ただし期限後入金の印を付ける
- D-RV11-0415 振込期限を過ぎても未振込の予約は、予約担当が確認してから取り消す。J110 は自動で取り消さない
- D-RV11-0416 銀行休業日に振り込まれた分は、翌営業日のファイルに、翌営業日の勘定日で入る

## 守ること

- D-RV11-0417 J110 が行う遷移は 未振込(0) → 振込済(1) だけで、他の遷移はしない
- D-RV11-0418 1つの予約に、消込に使った明細は1件まで
- D-RV11-0419 トレーラーの合計件数・合計金額が、データレコードの件数・金額の合計と一致すること
- D-RV11-0420 明細件数 = 消込件数 + 不一致件数 + 返金対象件数 + 要確認件数
- D-RV11-0421 明細の合計金額 = 消込金額 + 不一致金額 + 返金対象金額 + 要確認金額
- D-RV11-0422 1明細の、予約の更新と取込結果の登録は、両方成功するか両方失敗する
- D-RV11-0423 データ区分が 1・2・8・9 以外のレコードがあれば、形式エラーにする
- D-RV11-0424 金額が数字でない明細があれば、形式エラーにする
