# F-RV-11 振込データ取込（夜間バッチ） — ジョブ設計

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## ジョブネット

- D-RV11-0201 /TOUR/NIGHTLY: J110 振込取込 → J120 残席突合 → J310 予約一覧表
- D-RV11-0202 J110 は S1 受信確認・S2 形式検査・S3 消込・S4 リスト出力・S5 退避 の5ステップ
- D-RV11-0203 J110 は振込入金通知ファイルの到着で起動する
- D-RV11-0204 6:00 までにファイルが届かなければ起動せず、運用担当に知らせる
- D-RV11-0205 銀行休業日の翌朝はファイルが来ないので、J110 を起動しない
- D-RV11-0206 J120 残席突合は、J110 が終了コード 0 または 4 で終わった後に動く
- D-RV11-0207 J110 が終了コード 8 で終わったら、J120・J310 は実行しない

## 処理の単位と再実行

- D-RV11-0208 S3 の消込は500明細ごとにコミットする
- D-RV11-0209 J110 は途中で止まっても最初から再実行してよい。消込済みの明細は二重に消し込まない
- D-RV11-0210 再実行のときは、取込結果テーブルに同じ勘定日・照会番号がある明細を読み飛ばす
- D-RV11-0211 J110 が動いている間は、ロックファイル /var/run/tour/J110.lock で同じジョブの起動を止める

## 時間と資源

- D-RV11-0212 J110 は平常10分以内、繁忙期でも30分以内に終える
- D-RV11-0213 夜間ジョブネット全体は、7:00 の窓口開店までに終える
- D-RV11-0214 J110 は 1GB 以内のメモリで動く

## 終了コードと日付

- D-RV11-0215 J110 の終了コードは 0 正常、4 不一致・返金対象・要確認あり、8 異常
- D-RV11-0216 J110 の処理日は業務日付を使い、システム日付は使わない
