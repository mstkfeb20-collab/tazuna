# F-RV-41 旧予約システムからのデータ移行

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 機能構成・処理概要

- D-RV41-001 F-RV-41 データ移行。旧予約システムの予約とツアー情報を新システムに移す

## 移行・互換性

- D-RV41-002 旧システムの入金区分 'N'（未入金）は TRANSFER 0、'Y'（入金済）は 1、取消フラグが立った予約は 9 に移す
- D-RV41-003 移行前後で、予約件数・合計金額の総額・ツアーごとの残席数が一致すること
- D-RV41-004 移行後2週間は、旧システムでも同じ予約を登録して結果を突き合わせる
- D-RV41-005 旧システムの予約照会 API を使う提携サイトのため、同じ応答項目を返す API を残す
- D-RV41-006 旧システムで残席がマイナスのツアーは、移行前に予約担当が個別に補正する
