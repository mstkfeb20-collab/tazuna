# F-RV-11 振込データ取込（夜間バッチ）

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 機能構成・処理概要

- D-RV11-001 F-RV-11 振込データ取込。銀行から届く振込データで、予約を振込済にする
- D-RV11-002 予約担当が毎朝手作業で行っている入金の消込をなくし、振込済への更新を当日中に済ませる
- D-RV11-003 振込額が予約の合計金額と一致した明細だけを消し込む
- D-RV11-004 消し込めなかった明細は、すべて不一致リストに出ている

## 業務ロジック

- D-RV11-005 銀行休業日に届いた振込は、翌営業日の取込で処理する
- D-RV11-006 同じ予約に振込が2件あったときは先に届いた1件だけを消込に使い、もう1件は返金対象として予約担当に回す
- D-RV11-007 振込期限は予約日から7日後。過ぎても未振込の予約は、予約担当が確認してから取り消す

## トランザクション・整合性

- D-RV11-008 毎晩、ツアーごとに 残席数 + 有効な予約人数 = 定員 を突き合わせ、ずれたら予約担当に知らせる

## 外部インタフェース・連携

- D-RV11-009 IF-11: 銀行の振込入金明細ファイル（全銀協フォーマット）を受け取る
- D-RV11-010 振込入金明細はデータレコード200バイト固定長。振込依頼人名の先頭に予約番号が入る
- D-RV11-011 振込入金明細は Shift_JIS（半角カナ）、改行 CRLF
- D-RV11-012 振込入金明細は /data/inbound/bank に置かれ、batch ユーザーだけが読める
- D-RV11-013 取込済みと同じファイル名・同じ件数のファイルは取り込まない

## バッチ・ジョブ

- D-RV11-014 /TOUR/NIGHTLY: J110 振込取込 → J120 残席突合 → J310 予約一覧表
- D-RV11-015 J110 は振込入金明細ファイルの到着で起動する。6:00 までに届かなければ起動せず通知する
- D-RV11-016 J120 残席突合は J110 の正常終了後に動く
- D-RV11-017 振込明細は500件ごとにコミットする
- D-RV11-018 J110 は途中で止まっても最初から再実行してよい。消込済みの明細は二重に消し込まない
- D-RV11-019 J110 が異常終了したら J120・J310 は実行しない
- D-RV11-020 夜間ジョブは 7:00 の窓口開店までに終える
- D-RV11-021 取込済みの振込入金明細は日付を付けて退避し、13か月分保持する
- D-RV11-022 J110 が動いている間は、同じジョブを重ねて起動しない
- D-RV11-023 消込の対象は TRANSFER = 0（未振込）の予約だけ
- D-RV11-024 明細件数 = 消込件数 + 不一致件数、明細の合計金額 = 消込金額 + 不一致金額 になること
- D-RV11-025 J110 が異常終了したら、入力ファイルを退避してから運用担当が再実行する
- D-RV11-026 0 正常、4 不一致あり（警告）、8 異常
- D-RV11-027 振込の消込日は、システム日付ではなく業務日付（銀行の勘定日）にする

## 例外・エラー処理

- D-RV11-028 J110 の異常終了と不一致の発生は、運用担当と予約担当にメールで知らせる

## 性能・容量

- D-RV11-029 J110 は 1GB 以内のメモリで動く
