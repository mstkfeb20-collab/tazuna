# F-RV-02 予約登録 — メッセージ

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 入力エラー

- D-RV02-0701 E-RV-001 {0}を入力してください（必須項目が空のとき）
- D-RV02-0702 E-RV-002 {0}は{1}文字以内で入力してください
- D-RV02-0703 E-RV-003 電話番号は半角数字10〜11桁で入力してください
- D-RV02-0704 E-RV-004 メールアドレスの形式が正しくありません
- D-RV02-0705 E-RV-005 メールアドレスと確認用のメールアドレスが一致しません
- D-RV02-0706 E-RV-006 氏名カナは全角カタカナで入力してください
- D-RV02-0707 E-RV-007 {0}に使えない文字が含まれています

## 人数・代表者

- D-RV02-0708 E-RV-010 人数を入力してください（大人と子供の合計が0人のとき）
- D-RV02-0709 E-RV-011 お子様のみのご予約はお受けできません
- D-RV02-0710 E-RV-012 1回のご予約は9名までです。10名以上は店舗にご相談ください
- D-RV02-0711 E-RV-013 このツアーは大人の方のみご予約いただけます
- D-RV02-0712 E-RV-014 代表者は出発日の時点で18歳以上の方を指定してください

## ツアー・予約の状態

- D-RV02-0713 E-RV-020 このツアーは現在ご予約いただけません（存在しない・販売中でないとき）
- D-RV02-0714 E-RV-021 ご予約は出発日の7日前までです
- D-RV02-0715 E-RV-022 残席が不足しています（残り{0}席）
- D-RV02-0716 E-RV-022 の残り席数は、確定を試みた時点の残席数を出す
- D-RV02-0717 E-RV-023 同じツアーのご予約がすでにあります（予約番号 {0}）
- D-RV02-0718 E-RV-024 パスポートの写しを添付してください
- D-RV02-0719 E-RV-025 添付できるのは5MBまでのPDF・JPEGです
- D-RV02-0720 I-RV-001 ご予約を受け付けました
- D-RV02-0721 受付メールの件名は「【ツアー予約】ご予約受付のお知らせ（予約番号 {0}）」
- D-RV02-0722 残席不足・重複予約は業務エラーとして WARN、版番号の競合が2回続いたらシステムエラーとして ERROR
