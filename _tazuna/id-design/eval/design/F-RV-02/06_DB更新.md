# F-RV-02 予約登録 — DB更新

> 振り分け評価のインプット。1行に1つの決定事項を書く。設計項目や振り分け先は書かない。

## 更新するテーブル

- D-RV02-0601 RESERVE に1件 INSERT、TOURINFO の残席数を UPDATE、ARRANGE_QUEUE に1件 INSERT、OPERATION_LOG に1件 INSERT する
- D-RV02-0602 予約登録では RESERVE を UPDATE・DELETE しない

## RESERVE の列

- D-RV02-0603 RESERVE.RESERVE_NO VARCHAR2(13)
- D-RV02-0604 RESERVE.TOUR_CODE CHAR(8)
- D-RV02-0605 RESERVE.MEMBER_NO CHAR(10)
- D-RV02-0606 RESERVE.ADULT_COUNT NUMBER(1)、RESERVE.CHILD_COUNT NUMBER(1)
- D-RV02-0607 RESERVE.SUM_PRICE NUMBER(9)
- D-RV02-0608 RESERVE.TRANSFER CHAR(1)
- D-RV02-0609 RESERVE.PAY_DUE_DATE DATE
- D-RV02-0610 RESERVE.REPRESENTATIVE_NAME NVARCHAR2(20)、RESERVE.REPRESENTATIVE_KANA NVARCHAR2(40)
- D-RV02-0611 RESERVE.BIRTH_DATE DATE
- D-RV02-0612 RESERVE.TEL VARCHAR2(11)、RESERVE.MAIL VARCHAR2(256)
- D-RV02-0613 RESERVE.REMARKS VARCHAR2(240 BYTE)。80文字 × UTF-8 最大3バイト
- D-RV02-0614 RESERVE.PASSPORT_FILE_ID VARCHAR2(36)
- D-RV02-0615 RESERVE.REQUEST_TOKEN VARCHAR2(36)
- D-RV02-0616 RESERVE.VERSION NUMBER(9)
- D-RV02-0617 RESERVE の主キーは RESERVE_NO
- D-RV02-0618 RESERVE.REQUEST_TOKEN に一意制約を付ける
- D-RV02-0619 RESERVE.TOUR_CODE は TOURINFO.TOUR_CODE を参照する
- D-RV02-0620 RESERVE.MEMBER_NO は MEMBER.MEMBER_NO を参照する
- D-RV02-0621 RESERVE.TRANSFER は NOT NULL、初期値 '0'
- D-RV02-0622 RESERVE.REMARKS と PASSPORT_FILE_ID は NULL 可、それ以外の列は NOT NULL
- D-RV02-0623 RESERVE.TRANSFER: '0' 未振込、'1' 振込済、'9' 取消

## 画面と列の対応

- D-RV02-0624 代表者氏名・カナ・電話番号は、正規化した後の値を RESERVE に入れる
- D-RV02-0625 お客様の予約では、MEMBER_NO にログイン中の会員番号を入れる（画面から送られた値は使わない）
- D-RV02-0626 CREATED_BY・UPDATED_BY には、お客様なら会員番号、窓口担当なら社員番号を入れる

## 検索・性能・トランザクション

- D-RV02-0627 重複チェックは RESERVE を MEMBER_NO・TOUR_CODE と TRANSFER <> '9' で検索する
- D-RV02-0628 RESERVE に MEMBER_NO＋TOUR_CODE の索引を作る（重複チェック用）
- D-RV02-0629 ReservationService#reserve の1メソッドを1トランザクションとする
- D-RV02-0630 TOURINFO → RESERVE → ARRANGE_QUEUE の順に更新する
- D-RV02-0631 予約確定のトランザクションは500ミリ秒以内に終える
- D-RV02-0632 Reservation エンティティの桁数・NULL 可否は RESERVE の DDL と一致させる
- D-RV02-0633 RESERVE は年間約30万件増える。販売開始日は1時間に最大3千件登録される
