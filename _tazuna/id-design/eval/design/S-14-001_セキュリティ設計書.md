# S-14-001 セキュリティ設計書：セキュリティ設計書

> 振り分け評価のインプット。設計項目の見出しの下に、1行に1つの決定事項を書く。振り分け先は書かない。

## D-11001 認証方式

- S-14-001-001 窓口担当は社内SSO、お客様は会員IDとパスワードでログインする

## D-11004 出力のエスケープ

- S-14-001-002 画面に出す値は必ずエスケープする

## D-11005 SQLインジェクション対策

- S-14-001-003 SQL にはバインド変数を必ず使う

## D-11006 CSRF対策

- S-14-001-004 更新系のリクエストには CSRF トークンを必須にする

## D-11007 秘密情報の管理

- S-14-001-005 手配 API の認証キーは秘密管理サービスから読み、コードや設定ファイルに書かない

## D-11008 暗号化

- S-14-001-006 通信は TLS1.2 以上。会員のパスワード以外に暗号化して保持する項目はない
- S-14-001-007 パスポートの写しは保存するときに暗号化する

## D-11009 パスワード・トークンの扱い

- S-14-001-008 パスワードは bcrypt で保存し、再設定用のトークンは30分で無効にする

## D-11010 依存ライブラリの脆弱性

- S-14-001-009 重大な脆弱性のある依存ライブラリがあればビルドを止める

## D-11011 セッション管理

- S-14-001-010 ログインしたらセッションIDを再発行する
